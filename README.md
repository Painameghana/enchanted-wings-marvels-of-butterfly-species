# enchanted-wings-marvels-of-butterfly-species

# 🦋 Butterfly Species Classifier

A deep learning project for classifying **75 species of butterflies** using a CNN model trained on **6.5K images**.  
Deployed as a **Flask microservice** with a React.js frontend for seamless ML–UI integration.

## 🚀 Features
- CNN-based image classification
- 75 classes, 6.5K dataset images
- Flask backend for inference
- React.js frontend for image upload & results
- End-to-end ML pipeline deployment

## 🛠️ Tech Stack
- Python, TensorFlow, Keras
- Flask, REST APIs
- React.js, TailwindCSS
- Git, GitHub
